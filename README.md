# H&R.YAD Download Page

This repository contains a static download page for the H&R.YAD Windows package.

## What is included
- `index.html` — static download page

## Next step to make the site live
1. Enable GitHub Pages in repository settings.
   - Go to **Settings > Pages**.
   - Select **main** branch and **root** folder.
   - Save.
2. Upload `H&R.YAD-1.0.0-win.zip` to the repository or as a GitHub Release asset.
3. Share the published URL, which will look like:
   `https://haithamalaa98.github.io/hr-yad-download/`

## How to upload the ZIP
- The easiest way is to create a release and attach the ZIP file.
- Or upload the ZIP directly to the repository root using GitHub's file upload.

Once the ZIP is uploaded, the download button on the page will work.
